# Project 25 – Water Usage & Conservation Analysis

## Project Description
This project analyses household water consumption data using Python. It helps identify consumption patterns, compare household types and zones, and detect households with high water usage.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Dataset Information
The dataset contains 862 meter records and includes:
- Meter Record ID
- Household ID
- Reading Date
- Household Type
- Building Type
- Zone
- Water Usage (Litres)

## Tasks Completed
1. Dataset loading and inspection
2. Duplicate record identification
3. Missing value handling
4. Date conversion and extraction
5. Total and average water consumption
6. Monthly consumption change analysis
7. Household type ranking
8. Building type and zone analysis
9. High-consumption household identification
10. Zone-wise household type analysis
11. Monthly consumption analysis
12. Summary report
13. Exporting analysis results to CSV
14. Monthly consumption chart
15. Household type consumption chart
16. Zone-wise consumption chart

## Project Outputs
The outputs folder contains:
- Cleaned water dataset
- Household type analysis
- Building type analysis
- Zone analysis
- High-consumption household report
- Monthly consumption report
- Three data visualization charts

## How to Run the Project
1. Clone or download this repository.
2. Install the required libraries using:

   `pip install -r requirements.txt`

3. Run the Python program:

   `python main.py`

## Conclusion
This project demonstrates how Python can be used to clean, analyse and visualize household water consumption data to understand usage patterns and support water conservation analysis.
